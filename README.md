# 无是霉山的个人空间

GitHub Pages 个人站点：<https://wushimeishan.github.io>

记录前端学习、项目练习，以及对 AI、后端工程和 Agent 工程的探索。

## 本地预览

在仓库根目录启动任意静态服务器，例如：

```bash
python -m http.server 8080
```

然后打开 `http://127.0.0.1:8080/`。

## 页面

- `index.html` 首页
- `about.html` 关于我
- `projects.html` 项目
- `blog.html` 文章

右下角阿米娅是站点互动组件：点击会播放动作和语音，拖动会换成坐下姿势并可摆动（会记住位置），可用 ♪ 静音，或用 – 收起。
